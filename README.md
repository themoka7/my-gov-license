제110~139회 **공식 문제지 원문**에서 추출한 전 교시 기출 **868문항**(28개 회차 — 1교시 364 + 논술형 504)과,
시험장에서 그대로 재현할 **답안지 1면 분량 모범답안**을 담은 단일 페이지 학습 자료.

1교시는 지식 시험이 아니라 **속기 시험**입니다. 아는 걸 다 쓰면 시간이 모자라고, 채점 키워드만
골라 1페이지에 배치하면 통과합니다. 그래서 이 자료는 **시험용 답안 카드**와 **이해용 해설**을
분리해 두었습니다 — 이해는 해설로, 암기는 카드로 합니다.

## 시험 구조 (문제지 원문에서 확인)

| 교시 | 형식 | 출제 / 선택 | 배점 | 시간 | 문제당 |
|---|---|---|---|---|---|
| 1교시 | 단답형(용어) | **13문제 중 10문제 선택** | 10점 × 10 = 100점 | 100분 | 약 9분 |
| 2~4교시 | 논술형 | **6문제 중 4문제 선택** | 25점 × 4 = 100점 | 각 100분 | 약 24분 |

- 합격선은 **400점 만점 평균 60점(240점)**. 만점을 노리는 시험이 아니라 **과락 없이 240점을 모으는** 시험.
- 1교시는 "10문제를 푸는" 시험이 아니라 **13문제 중 3문제를 버리는** 시험입니다. 시작 후 4~5분은
  펜을 들지 말고 13문제를 전부 읽어 ◎(도해까지 가능) / ○(표는 채움) / ×(버림)으로 분류하는 것이
  가장 큰 득점 수단입니다.

## 답안 작성 원칙

1교시는 문제의 **동사**를 보고 5개 템플릿 중 하나를 꺼내 씁니다. 자세한 골격은 학습 페이지의
「1교시 유형별 템플릿」 절에 있습니다.

| 유형 | 문제의 동사 | 도해 | 중심 무기 |
|---|---|---|---|
| A 정의·개념형 | "~에 대하여 설명하시오" | 선택 | 구성요소 표 |
| B 비교형 | "A와 B를 비교하시오" | 불필요 | 1:1 비교표 |
| C 절차·프로세스형 | "~절차/단계를 설명하시오" | 필수(흐름) | 단계별 표 |
| D 아키텍처·구성형 | "~의 구성요소를 설명하시오" | 필수(계층) | 계층 도해 + 표 |
| E 이슈·대응형 | "~문제점과 대응방안" | 불필요 | 3단 프레임 표 |

공통 규칙 — **분량은 답안지 1면 고정**(1.2면은 시간 초과), 번호 체계는 `I. → 1. → 가. → 1)`
4단계까지만, 모든 문항 답안 끝에 우측 정렬로 **"끝."** 기재, 시간이 부족하면
**축약형**(개요 3줄 + 표 3행 + 끝.)으로 6점을 확보합니다.

표를 쓰는 이유는 보기 좋아서가 아니라 **같은 지면에 채점 키워드를 3배 넣을 수 있어서**입니다.
줄글 3줄에 키워드 2개가 들어가는 자리에, 3행 표는 항목명 3개 + 설명 키워드 6개가 들어갑니다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 학습 페이지 본체. 이 파일 하나가 곧 페이지입니다 |

| `tools/extract_1gyosi.py` | 문제지 → 1교시 13문항 파싱 |
| `tools/extract_essay.py` | 문제지 → 논술형 2~4교시 18문항 파싱 (소문항 포함) |
| `tools/build_pages.py` | 아티팩트 조각 → 정적 호스팅용 완전한 문서 빌드 |
| `.github/workflows/pages.yml` | main 푸시 시 GitHub Pages 자동 배포 |

`index.html`은 외부 의존성이 없는 단일 파일입니다. 브라우저로 바로 열어도 동작하며,
글꼴(Google Fonts)만 네트워크에서 가져옵니다.

### 왜 빌드 단계가 있나

`index.html`은 **Claude Artifact 용 조각**입니다 — `<!doctype>`·`<html>`·`<head>`가 없고,
아티팩트 플랫폼이 발행할 때 charset·viewport·기본 리셋을 감싸줍니다.

이 파일을 정적 호스팅이 그대로 서빙하면 **quirks 모드로 렌더링되고, viewport 메타가 없어
모바일에서 데스크톱 폭으로 축소**됩니다. 그래서 `tools/build_pages.py`가 배포 시점에
완전한 문서로 감싸 `_site/index.html`을 만듭니다. 원본은 하나로 유지하면서 두 곳에
모두 올바르게 올라가게 하는 장치입니다.

```bash
python3 tools/build_pages.py   # → _site/index.html
```

### GitHub Pages 배포

`main`에 `index.html`이 푸시되면 `.github/workflows/pages.yml`이 빌드 후 배포합니다.

**최초 1회만 저장소 설정이 필요합니다** — `Settings → Pages → Build and deployment`의
**Source를 `GitHub Actions`로** 지정하세요. `Deploy from a branch`로 두면 빌드 단계를
건너뛰고 조각 파일이 그대로 서빙되어 모바일 레이아웃이 깨집니다.

## 회차 추가하는 방법

1. 문제지 파일을 저장소 루트에 올립니다. **파일명에 `NNN회`가 포함**되어야 회차가 인식됩니다.
   파일명에 `(YYYY년)`이 있으면 시행연도까지 함께 표기됩니다.
2. 텍스트 추출 후 파싱합니다.
   ```bash
   python3 -m venv v
   ./v/bin/pip install pypdf pyhwp six olefile

   # PDF → 텍스트
   ./v/bin/python -c "
   import glob,re,os
   from pypdf import PdfReader
   os.makedirs('txt',exist_ok=True)
   for f in glob.glob('*.pdf'):
       n=re.search(r'(\d+)회',f).group(1)
       open('txt/%s.txt'%n,'w').write('\n'.join((p.extract_text() or '') for p in PdfReader(f).pages))
   "
   # HWP → 텍스트
   ./v/bin/hwp5txt '제116회 정보관리기술사(2018년).hwp' > txt/116.txt

   # 1교시 13문항 파싱 → all1.json
   SP=. ./v/bin/python tools/extract_1gyosi.py
   ```
3. 생성된 `all1.json`을 `index.html`의 회차 섹션에 반영합니다.

파서는 세 가지 양식을 모두 처리합니다.

| 양식 | 안내문 | 해당 회차 |
|---|---|---|
| 신 양식 | `※ 총 13문제 중 10문제를 선택하여 설명하시오` | 133회 이후 |
| 구 양식 | `※ 다음 문제 중 10문제를 선택하여 설명하시오` (문항 수 미표기) | 110~132회 |
| HWP | 안내문이 표 안에 있어 미검출 → 첫 페이지 기준 파싱 | 116회 |

표기가 있는 15개 회차 전부에서 교시 번호가 수록 순서와 일치함을 확인한 것이 추정 근거입니다.

### 논술형 답안 형식

논술형은 문항당 **3페이지 · 25점**이라 504문항 전문 작성은 비현실적입니다. 그래서 혼합 방식을 씁니다.

| 형식 | 대상 | 내용 |
|---|---|---|
| **목차 골격** | 전 문항 | 대제목 I~V, 배점·분량 배분, 절별 표 구성과 도해 지시, 채점 키워드 |
| **전문** | 회차당 2문항 | 1교시 답안과 같은 밀도로 3페이지 전문. 재출제 가능성이 높은 주제 선별 |

서술형은 3페이지를 암기하는 시험이 아니라 **"대제목을 무엇으로 잡고 어느 절에 표를 넣을지"**를 아는 시험이므로,
골격과 채점 키워드가 실제 득점에 직결합니다. 최근 회차가 출제 경향에 가장 가깝고,
구 회차(110~120회)에는 현재 출제되지 않는 주제(파스-타 3.0, 제로 레이팅 등)가 섞여 있어
투자 효율이 떨어집니다.

## 출처

문제 본문은 한국산업인력공단 Q-Net에 공개된 **국가기술자격 기술사 시험문제** 원문입니다.
채점기준과 기준답안은 「공공기관의 정보공개에 관한 법률」 제9조 제1항 제5호에 따라 비공개이므로,
이 저장소의 답안은 **모범답안이 아니라 학습용으로 작성한 답안 골격**입니다.
시험 구조·배점은 응시 회차의 수험자 안내로 최종 확인하시기 바랍니다.
