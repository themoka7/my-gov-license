# 정보관리기술사 1교시 학습 노트

제110~139회 공식 문제지에서 추출한 **1교시 단답형 기출 364문항**(28개 회차, 제112·115회 미보유)과
회차별 모범답안을 담은 단일 페이지 학습 자료. 답안은 최신 회차부터 순차 작성 중.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 학습 페이지 본체 (PC·모바일 대응, 진도 체크는 아티팩트 `db`로 기기 간 동기화) |
| `제1NN회 정보관리기술사*.pdf` / `.hwp` | 원본 문제지 (PDF 27종 + HWP 1종) |
| `tools/extract_1gyosi.py` | 문제지 PDF → 1교시 13문항 파싱 스크립트 |

## 시험 구조 (문제지 원문 확인)

- **1교시** 단답형: 13문제 중 **10문제 선택**, 각 10점, 100분 → 문제당 약 9분
- **2~4교시** 논술형: 6문제 중 **4문제 선택**, 각 25점, 100분 → 문제당 약 24분
- 400점 만점 **평균 60점(240점)** 합격

## 회차 추가하는 방법

1. 문제지 PDF를 저장소 루트에 올린다 (파일명에 `NNN회` 포함).
2. 텍스트 추출 후 파싱:
   ```
   python3 -m venv v && ./v/bin/pip install pypdf pyhwp six olefile
   # PDF: pypdf 로 텍스트 추출, HWP: ./v/bin/hwp5txt 사용
   SP=. ./v/bin/python tools/extract_1gyosi.py
   ```
3. 생성된 `all1.json`을 `index.html`의 회차 섹션에 반영한다.

파서는 신·구 문제지 양식(`13문제 중 10문제` / `다음 문제 중 10문제`)과 안내문이 없는
HWP 양식을 모두 처리한다.
